# Instagram DM flow (operational)

1. **Bio + pinned comment:** “Message **CLARITY** for the 2-minute check-in link.”
2. **Auto-reply (ManyChat / Meta):** “Here’s the clarity check-in: [funnel URL]. It takes about two minutes. If you want a human to translate your results, call [phone] or book on the last screen.”
3. **CRM:** Create/update contact; tag `source:instagram_dm`, `keyword:clarity`.
4. **If they already completed the quiz:** Route to a different auto-reply (“Thanks! A strategist will follow up — want a call-back window?”).
5. **Story reply:** Tag `source:instagram_story_reply`; same first message with UTM: `?utm_source=ig&utm_medium=story_reply`.

Pair with `docs/instagram-content-engine.md` for creative.
